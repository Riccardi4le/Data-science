## Projects

### ✈️ Aerial Satisfy — Passenger Satisfaction Prediction
> **Type:** Binary Classification &nbsp;|&nbsp; **Domain:** Aviation / UX

Predict whether airline passengers are satisfied or dissatisfied based on flight and service features. Applies feature engineering and model selection to achieve high predictive accuracy.

**Key techniques:** Logistic Regression, Random Forest, XGBoost, Feature Importance analysis  
**Dataset:** ~130,000 passenger records

📓 [Open Notebook](notebook/Progetto%20Aerial%20Satisfy.ipynb)

---

### 🛡️ Email Phishing Detection
> **Type:** NLP / Text Classification &nbsp;|&nbsp; **Domain:** Cybersecurity

Detect phishing emails using natural language processing and supervised learning. Explores TF-IDF vectorization and multiple classification algorithms.

**Key techniques:** TF-IDF, Naive Bayes, SVM, Precision/Recall analysis  
**Goal:** Minimize false negatives to protect users from fraud

📓 [Open Notebook](notebook/Progetto%20Email-Phishing%20Detection.ipynb)

---

### 💰 Loan Risk Modeling
> **Type:** Risk Classification &nbsp;|&nbsp; **Domain:** Finance

Analyze borrower profiles and predict loan default probability. Includes exploratory data analysis, class imbalance handling, and model evaluation with financial metrics.

**Key techniques:** Decision Trees, SMOTE, ROC-AUC, Cost-sensitive learning  

📓 [Open Notebook](notebook/Progetto%20prestiti.ipynb)

---

### 🌍 Food Waste & Global Malnutrition Analysis
> **Type:** Exploratory Data Analysis &nbsp;|&nbsp; **Domain:** Global Health / Sustainability

Investigate correlations between food waste patterns and malnutrition rates across countries. Combines multiple public datasets with geospatial and statistical analysis.

**Key techniques:** Correlation analysis, Seaborn visualizations, Pandas merging, Hypothesis testing  

📓 [Open Notebook](notebook/Food%20analysis.ipynb)
